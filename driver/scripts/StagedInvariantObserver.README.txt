StagedInvariantObserver / schema StagedInvariant/1 -- Phase 4 WP1

Windows PowerShell 5.1 / .NET Framework, one embedded C# 5 helper. No driver,
agent, service, verifier, scheduled task or external executable dependency.
This is observer code, not a completed Phase 4 suite or qualification claim.
Import with -DisableNameChecking (contract verbs are intentional). Serialize
API calls for each context; continuous polling shares one observer work queue.
Use a fresh powershell.exe process for every exact artifact set; importing
changed module bytes into a process with an old helper is rejected.

API (positional order also supported)
  Open-InvariantObserver VolumeGuid ScopePath EvidenceDirectory CaseId
    Elevated; GUID must be \\?\Volume{...}\ including trailing backslash.
    Scope must exist on fixed NTFS, with no reparse ancestor. Requires build
    19045.2965. Evidence must be a new unique directory outside scope.
  Capture-InvariantBaseline Context DestinationNames ExpectedImages
    Names: 1..256 relative names (include public temps and expected absences).
    Baseline capture is one-use per context; duplicate/case-ambiguous names fail.
    ExpectedImages: hashtable name -> independently generated byte[], or null
    for absence. Empty byte[] means existing empty file. Caller durably flushes
    legitimate setup FIRST. The observer NEVER flushes a subject or volume.
  Register-InvariantPublication Context ApprovalRecord SealedImage
    SealedImage: byte[], copied and hashed independently. Register before any
    public temp write. ApprovalRecord field list below. No fixture token counts.
  Capture-InvariantSample Context Baseline Phase OperationSequence
    Full raw/reader capture; retains original and observed approved final IDs.
    Stable bracket required. Retries only instability, <=10 attempts, with a
    2-second retry-entry deadline. Native synchronous I/O cannot be interrupted
    at that deadline. Actual duration/gaps and every partial attempt survive.
  Test-NoUnapprovedByte Baseline ApprovedImages Samples MutationLedger
                        ExpectedTimeline
    Returns assertions/verdict. No ledger/actor/timeline evidence => INCONCLUSIVE.
    Recorded FAIL takes precedence, including a violation in a partial capture.
  Close-InvariantObserver Context
    Checked close of held handles and volume. Always call in finally. Check the
    disposal record; incorporate it in the coordinator's final result.

Result schema (JSON fields; PascalCase; optional fields on failure)
  Each PowerShell object has PSTypeName StagedInvariant.<kind>; serialize values
  with ConvertTo-Json -Depth 32. PSTypeName is not itself a JSON field.
  Context: Schema, Status, Closed, CaseId, ScopePath, EvidenceDirectory,
    Geometry, DecoderVersion, ModuleSha256, BootId, Build, TargetBuildSupported, ObserverPid,
    ObserverSid, BootstrapArtifacts, InitialScope, Publications, NextSequence,
    LastSampleQpc, LastSampleStartQpc, BaselineCaptured, Errors. Volume and Handles are runtime-only: omit them from
    JSON and never serialize/reconstitute a live context.
  Geometry: Guid, Mount, Device, Serial, Sector, PhysicalSector, Alignment,
    Cluster, RecordSize, IndexSize, MftLcn, TotalBytes.
  Time: Utc, Qpc, QpcFrequency, BootId. BootId = machine/OS boot UTC identity.
  Baseline: Schema, Status, CaseId, Time, Names, Images, Readers, Geometry, Build,
    ObserverPid, ObserverSid, Error; failed capture may include Partial.
  ApprovedImage: Status, Time, Approval, Length, Sha256, SnapshotArtifact, Error.
  Sample: Schema, Status, CaseId, Sequence, OperationSequence, Phase, Start, End,
    GapMs (idle interval after preceding pass), CadenceMs (start-to-start),
    DurationMs, Attempts, Captures,
    Images, Readers, Error, CleanupErrors. Attempt: Attempt, StartQpc, EndQpc,
    Status, Error. Capture: Status, Images, Readers, Error.
  StorageImage: Path, Role, Absent (Current only), Identity, RawMetadata,
    Resident, CrossCheckErrors, Length, Sha256, Runs, Attributes, FileNames,
    DirectoryEntries,
    SecurityId, Sddl, Records, Containers, LogicalArtifact, Fingerprint;
    RetainedVersion for retained IDs. Absence: Path, Role, Absent, ParentReference.
  Identity: VolumeSerial, Reference (NTFS number+sequence), FileId (full 128-bit
    uppercase hex), Allocation, Eof, Creation, Modified, Changed, Accessed,
    Attributes, Links, Directory, DeletePending. RawMetadata contains raw
    STANDARD_INFORMATION times/attributes and queried Links. NTFS times are
    integer FILETIME values, not UTC text.
  Run: Vcn, NextVcn, Lcn, Clusters. Lcn=-1 is a hole, never an address.
  Attribute: Type, Id, Flags, Name, RecordReference, NonResident, StartVcn,
    LastVcn, Allocation, Eof, ValidData, CompressionUnit, Runs.
  Name: Name, Namespace (0 POSIX/1 Win32/2 DOS/3 Win32+DOS), Reference, Parent,
    Allocated, Eof, Attributes, Creation, Modified, Changed, Accessed.
  Record: Number, Sequence, BaseReference, RawSha256, FixedSha256.
  Container: Offset (volume-relative), Length, Kind, Artifact.
  Artifact: Path, Kind, Length, Sha256. Raw .bin and separate logical .bin are
    CreateNew + WriteThrough + Flush(true), with an append-only manifest.ndjson.
  HistoricalContainer: Role, OriginalFileId, Kind, Offset, Length,
    OriginalSha256, Artifact. Freed storage is history, never a new identity.
  PartialContainer: Role, Path, Containers (read before a decoder error).
  FreshReader: Path, Unbuffered, Status, Result, Error; held readers also have
    Role=Retained and FileId. Result: Before, After, Digest, Length, Status,
    NativeCode. The held supplemental reader is buffered, over the retained ID.
  Error: Phase, NativePhase, NativeCode (null when no native code), Verdict,
    Chain[]. Chain: Type, Message, HResult, Stack, NativeCode, NativePhase; includes
    inner exceptions and all aggregate cleanup exceptions.
  Verdict: Schema, Verdict (PASS/FAIL/INCONCLUSIVE), ForbiddenByteCount,
    Assertions, RawDifferences, AuthoritativeCaseExport=false. ForbiddenByteCount
    counts whole-image violation alarms, detected logical differences and first
    forbidden-block hits per artifact;
    repeated observations can count the same byte again. It is not a unique
    physical-byte total or a substitute for assertions/coverage.
  Assertion: Name, Verdict, Reason, SampleSequence, Path.
  RawDifference: Sequence, Role, Path/Kind/Offset as applicable, Before/After
    hashes, Artifact, FirstDifferenceOffset, DifferingBytes when comparable.
  Disposal: Status, Errors, Time. ERROR is never an empty-byte success.

Inputs from the future real service/table/ledger adapter
  ApprovalRecord: Source='ActualServiceJournalAndPermit', TransferId,
    DestinationGeneration, PolicyGeneration, EpochGeneration, TempPath,
    FinalPath, ExpiryUtc, ServiceSid, ServicePid, AttemptId, ApprovedLength,
    ApprovedSha256, PermitLength, PermitSha256, ApprovedQpc, PermitGrantQpc,
    ExpiryQpc, JournalSequence, PermitSequence, JournalIdentity, PermitIdentity,
    BootId, SnapshotImmutable=true,
    ActualServiceGrant=true. JournalIdentity and PermitIdentity each carry all
    envelope identity fields (TransferId through AttemptId, including paths,
    generations, expiry and principal); each must match the envelope. Journal
    additionally has State='Approved'; Permit has Granted=true. Digest must be uppercase SHA-256. These fields
    are adapter evidence, NOT authentication merely because a caller sets them.
  ExpectedTimeline: ForbiddenBlocks (array of byte[]; use ,$block to preserve
    a single block), PreCutoffImages, Checkpoints, AllowedMutations,
    ExpectedDenials, WriterIdentities, AccountedGapSequences, PlatformValidated,
    ObserverIndependent, StandardUserWriters, ContinuousObservationComplete,
    RestorationKnown. Adapter must substantiate every coverage boolean.
  WriterIdentity: Pid, Sid, Elevated, IsAdministrator, BootId. The module checks separation;
    trusted orchestrator must collect/validate tokens and independent processes.
  Checkpoint: Phase, OperationSequence, State, Storage[], Directories[],
    ReadDenials[]. Storage: Path, Kind=Final/Temp/Absent, Version=Baseline/
    PreCutoff/<AttemptId>, FileId, Generation, ZeroPadding, Metadata. Metadata:
    Attributes, Creation, Modified, Changed, Accessed, Links, SecurityId, Sddl.
    Final may have Alternates[] (same schema) for old/new whole-image replacement.
    Temp additionally: WrittenRanges[] {Offset,Length,FileId,LowerCompleted},
    Unwritten=Zero/Baseline. Directories: Path, Entries (complete Name schema),
    SecurityId, Sddl; optional Alternates[] with the same directory schema for
    an accounted publication transition. ReadDenial: Path, Unbuffered, NativeCode; Activating only.
  PreCutoffImage: Path, Bytes, Sha256, StoredBeforeQpc, EpochSwapQpc. No service
    approval is minted. Expected bytes/digest must be committed before cutoff.
  MutationLedger: Complete, Overflow, FirstSequence, LastSequence, Entries[].
    Entry: Sequence, PostComplete, LowerAdmitted, DeniedBeforeLower, Qpc, Path,
    FileId, VolumeSerial, SopIdentity, EpochGeneration, Operation, Paging,
    Offset, Length, NativeResult, AttemptId, PolicyGeneration,
    DestinationGeneration, PayloadSha256. AllowedMutations/ExpectedDenials
    carry the same exact fields/Sequence. AllowedMutation additionally Version,
    Generation, Class=TrustedSetup/SingleCutoffFlush/ExactMetadataTransition
    or publication class, BeforeCutoffStores, PermitActive, RevokeQpc.
    Writes are independently range-hashed from the indicated image. Adapter
    must prove expiry, revoke/disconnect, one temp create/one rename consumption,
    grant principals and exact transitions; table records cannot mint permits.
    Expiry/revoke prohibits subsequent lower writes, not previously approved
    bytes remaining in a temporary. An observed actual grant with a validation
    mismatch returns Error.Verdict=FAIL; retain that rejected registration.

Bounds and honest limits
  64 MiB EOF/decoded stream, 128 MiB mapped/physical allocation, 1 MiB raw chunks;
  256 records per base file, 1024 attributes/list entries, 8192 runs/pages,
  16384 directory entries/blocks/containers, 64 KiB FILE/INDX records.
  Attribute-list extensions must be reachable through the bootstrap MFT map;
  split attribute-list streams or inaccessible bootstrap extensions fail closed.
  Win32/DOS active index tree and bitmap checked; POSIX keys decoded too.
  Unnamed sparse data reconstructs holes as zero and archives actual allocation.
  LZNT1 only: gather full units, distinguish full/sparse/partial, use bounded
  Windows ntdll RtlDecompressBuffer with checked NTSTATUS and exact output size.
  No XPRESS/unknown formats, EFS, alternate data streams, reparse/hardlinks,
  case-sensitive fixtures, $Secure descriptor decoding, or general NTFS recovery.
  Owner/DACL is an OS cross-check against raw SecurityId, not raw $Secure proof.
  Changed compressed physical units, and changed/reused historical allocation
  without an ownership adapter, produce INCONCLUSIVE rather than being approved.
  Final compressed units that cannot expand to the full unit size fail closed.
  Raw metadata differences are reported separately; active semantics and unique
  forbidden blocks are judged. Arbitrary slack attribution and shared MFT-sector
  ownership are not an independent general-purpose forensic reconstruction.
  No background scheduler/10 ms guarantee, lower-ledger producer, service/journal
  reader, latency gate, lifecycle/restoration/verifier/task manager, or final
  authoritative case.json exporter. Caller supplies continuous passes/barriers,
  authenticated external evidence and exactly one final JSON after restoration.
  Open cannot validate writers not passed in its signature: actor provenance is
  validated at the predicate boundary with trusted adapter evidence. Sampling
  does not establish absence of transient writes between observations.

Orchestrator commands (from the staged source root; capture raw stdout/stderr)
  Builder, any Windows build, Windows PowerShell 5.1; no elevation/raw volume:
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\driver\scripts\StagedInvariantObserver.SelfCheck.ps1
  Guest, driver OFF, elevated, Windows 10 19045.2965, existing fixed-NTFS folder:
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\driver\scripts\StagedInvariantObserver.SelfCheck.ps1 -Live C:\IOFixtureRoot
  Both: require process exit 0 AND one IO_Summary with failed:0; preserve full
  output. Live creates unique io-fixtures-* and io-evidence-* below the supplied
  root and RETAINS both. Fragmentation requires >=3 actually observed extents;
  failure to achieve that is FAIL, not a skipped success. Read reported fixture
  and evidence paths before any later removal. No automatic broad cleanup.
  Scheduled execution: cache Process.Handle before wait, check nonnull ExitCode,
  task stopped state and LastTaskResult, durable unique completion/readiness.
  Do not substitute SSH/task creation success for the checks' result.
  Further WP2 VM work still required: actual sparse/compressed files, resident
  conversion, MFT fragmentation, replacement identities, allocation/EOF/slack
  and ledger write-then-erase. Synthetic cases do not qualify those live paths.
