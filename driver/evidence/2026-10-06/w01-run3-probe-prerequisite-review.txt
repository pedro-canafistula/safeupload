-------
The pinned b38 feature driver starts admission tracing disabled. In
SafeUploadStageInitialize, StageStream.c resets
SafeUploadAdmissionTraceControlState to 0 (line 2300). The first operation in
StageAdmissionProbeWorkerBody reads that state and returns
STATUS_DEVICE_NOT_READY when its enabled bit is clear (lines 559-560). The
run's pinned AfterBoot parent input invokes --admission-probe for the protected
control without first issuing --admission-trace-enable (line 855). Therefore
the Inspector reaches FilterSendMessage but the explicit probe is rejected by
the trace-state prerequisite before volume/path lookup. The later not-ready
branches at StageStream.c:611-614 and :685-691 require an enabled trace state
that changed during the probe; the pinned run's initialization and command
ordering do not support those as the cause here.

21)), written by Inspector after FilterConnectCommunicationPort succeeded and
FilterSendMessage returned. Its exit-code logic returns 3 for a failed HRESULT
or nonzero reply length. This is consistent with the first driver guard above.
