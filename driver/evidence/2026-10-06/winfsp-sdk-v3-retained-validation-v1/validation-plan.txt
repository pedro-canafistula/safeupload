WinFsp SDK v3 retained-output validation (read-only)
Status: authored for independent review; not executed or PowerShell-parsed.

Purpose and boundary

The v3 MSI administrative extraction returned native exit 0 and recorded the
complete standard AdminExecuteSequence, unchanged MSI bytes, and empty
WinFsp package/driver/service inventories. Its verifier exited 1 because
`msiexec|2272` remained after the client process returned. A read-only
diagnostic pinned PID 2272 as the Manual/Running Windows Installer service
process (`msiexec.exe /V`, parent PID 684). It confirmed all eight standard
actions, ADMIN, server/client engine return 0, and the successful completion
line in the unchanged 338,400-byte log. This shows extraction completion; it
does not show that the service process was idle. The validator therefore
requires every listed installer/build actor to be absent and `msiserver` to be
stopped before and after inspection. It neither waits for, stops, nor
reconfigures that service. Until natural drain, a run fails closed before it
walks or hashes the retained output.

This script only validates the existing target and log. It does not invoke
Windows Installer, repeat extraction, delete or write any target/log entry,
stop a process/service, change service configuration, or execute extracted
content. It verifies the already signed MSI's identity, size, SHA-256 and
Authenticode signer; holds read-only handles; checks pinned source/output
ancestor identities; verifies the retained target and log identities, log
length and digest; rejects reparse points and alternate data streams; and
hashes all regular files in a stable complete directory inventory. It derives
one SDK root only when that root contains both `inc\winfsp\winfsp.h` and
`lib\winfsp-x64.lib`. The required `ExpectedRetainedLogIdentity` is supplied
from the separately captured, hash-pinned read-only file-identity record; the
script compares it to the opened log handle and includes both values in its
JSON result.

Result meaning

Only `WINFSP_SDK_RETAINED_OUTPUT_VALIDATED` with empty before/after actor
inventories, stopped Windows Installer service, unchanged empty WinFsp
installed inventories, exact MSI/log/target identities, and complete hashes
qualifies this retained SDK directory as an input for a later feature-only
host build. This result does not qualify an installed runtime, service,
driver, live system, mapping behavior, privacy, or product build. The trusted
signer checkpoint parent and all key/trust state are outside this script's
scope and are not modified.
