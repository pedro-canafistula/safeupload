## Verification and rollback guards

Before signing each artifact, require that the exact signed-output path does not exist. Record the source unsigned artifact hash, copy it to the signed-output path without overwriting, and require the copy hash to equal that source hash immediately before signing. Sign the fresh copy with `/sm /fd sha256 /sha1 <new-thumb>`, then require SignTool exit 0, record the final signed hash, and verify with `Get-AuthenticodeSignature` that status is `Valid` and signer thumbprint is the exact new value; do not weaken this gate to accept `NotTrusted`. Preserve the separate unsigned artifact and its original hash. Package signing must cover both the `.sys` and `.cat`; the final package manifest must identify the new public certificate hash and exact thumbprint. Re-run the selected matrix-E driver/fault build gates and relevant exact-signer qualification gates. The already-passing agent tests/package matrix does not need repeating unless its code or package inputs change.

Remove only from the two machine stores; then require the new thumb to be absent from those stores and both inherited views, with every other full-store inventory entry unchanged. On the builder, remove the new thumb only from `CurrentUser\Root`, restore the pre-fallback checkpoint to remove the replacement machine key association, and confirm the original CurrentUser certificate, PFX/CER hashes, and complete store inventories. Retain the separate protected key-bearing checkpoint for later recovery.
