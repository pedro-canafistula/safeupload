Builder-only public SDK extraction, not runtime deployment.

independent review of this exact source and read-only MSI table evidence,
actual PS5.1 parse with zero errors, fresh GUID target under vika Documents.

Use only official checksum-pinned 2.2.26215 MSI already signature-read on builder.

no custom action or service/driver registration. Script rechecks this exact
sequence, official hash, Valid exact publisher, absence of installed WinFsp,
and absence of installer/build actors before msiexec /a /qn /norestart. It
creates only a fresh administrative image plus adjacent retained MSI log.

No extracted exe/dll/sys is executed. No trust/key/sign/build/git operation.

Retain all output and logs on failure; never invoke uninstall or delete source,
image, or logs. Independently compare post-extraction installed inventories and
public source hashes. Identify inc/winfsp plus x64 import library from manifest;
pass explicit WinFspSdkRoot to the future feature-only native host build.

load either kernel driver, report mapping privacy, or remove taint. Runtime
installation needs its own preserved disk and independently verified baseline.
