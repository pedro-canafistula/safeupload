## Findings

1. **Medium — symlinked directories can hide markers.** `Path.rglob('*')` does not recurse into symlinked directories by default, so a recovery marker beneath one can be missed and the run may proceed. `path.is_file()` also follows file symlinks, though an entry still needs an allowlisted relative path and matching content hash to be cleared.

2. **Low — the resolution bypass is available through the function API.** `recovery_markers(evidence, resolved=...)` accepts any caller-supplied mapping, and `load_disposition(path, pinned)` allows callers to supply a different note and pin. The production callsite uses `recovery_markers(evroot)` with defaults, and I found no other production callsite, so this is not currently exercised by the host.

3. **Low — narrow fail-closed caveats.** Missing, hash-mismatched, or ordinarily malformed notes return `{}`. A JSON top-level value that is not an object can raise uncaught `AttributeError` at `note.get`; that aborts preflight rather than allowing the run. There is also a check-then-read race: the note is hashed before it is parsed, and markers can change between scanning and use.
