# S01 writer TEMP/TMP source review

## Decision

I found no source blocker in this narrow change. In pinned `driver/scripts/Test-StagedInvariantSuite.ps1` (`SHA-256 F2C002221C48E10C863FC121E0E5A15EC07A041BAF453DAE1DE1C2A2474E0EB5`), the change inserts `$env:TEMP='__TEMP__';$env:TMP=$env:TEMP` as the first statements in `Get-WriterBody` before its `Add-Type`, then resolves the placeholder at generation using the existing PowerShell single-quoted string literal helper with `$actorDirectory`. The only other diff is that replacement. This keeps the compiler's temp output in the coordination directory the actor already must write for identity/go/completion; it does not grant that user a new directory or a new ACL.

The apostrophe escaping is suitable for this insertion context: `ConvertTo-PowerShellLiteral` doubles single quotes (suite line 125), and the expanded path is inside a single-quoted PowerShell string. The target root is the existing run-specific actor directory, created under the protected state directory. The actor has read/traverse on the state directory and Modify on the actor directory (lines 1637–1640); SYSTEM and Administrators retain full control from the state tree ACL setup. Other standard users do not receive a new grant. The inserted statements alter only this scheduled writer process's environment, before `Add-Type`; they do not modify global or machine TEMP/TMP.

The surrounding gates remain intact: the writer still verifies its current token SID, non-elevation and non-administrator membership before publishing identity (lines 443–448); the coordinator still validates identity/process provenance before creating `go` (lines 1425–1431); the writer still blocks until that go file and makes its existing 101 attempts (lines 449–459); and the 101 expected native-result assertions remain after successful completion (around lines 1458–1470). There is no diff to BootPolicy seed, trust/readiness checks, identity validation, native operation logic, denial acceptance, or restoration. The existing task is limited-run and the existing restoration removes its task and actor user; finalization removes the owned state directory after preserving the actor evidence (lines 1493 onward and 1790–1792). This patch adds no separate TEMP cleanup path or broader deletion.
