Admission diagnostic review fixes
Date: 2026-10-02

Decisions applied
- D1: StageStream.c:425-540 gates the probe on trace state, non-file-ID,
  non-FILE_CREATE, non-directory, fixed-volume, NTFS, and PASSIVE_LEVEL. It
  retains FILE_READ_ATTRIBUTES, full sharing, FILE_OPEN, FILE_NON_DIRECTORY_FILE,
  and FILE_OPEN_REPARSE_POINT. Rundown is acquired only after the lower create
  and cleanup; a result from a changed trace generation is dropped. Handle and
  file-object cleanup covers both successful and failed opens.
- D2: StageStream.c:405-422 and :1954-1987 record reason-coded directory,
  file-ID, create-disposition, network, removable, unknown-volume, non-NTFS,
  and non-PASSIVE skips. Protocol.h:280-290 defines the codes; ProbeSkips is
  included in the counters and Inspector output.
- D3: StageStream.c:374-403 no longer queries stream or instance contexts in
  operation capture. The paging-write and section hooks report
  SAFEUPLOAD_ADMISSION_TRACE_CONTEXT_NOT_QUERIED; Inspector prints
  "not_queried". Their volume kind remains unknown.
- D4: No admission-record table exists in slice 1. AdmissionRecordState stays
  "not_tracked"; this is part of the revised slice contract.
- D5: Inspector main.c:34, :514, and :763 uses the feature code only under an
  explicit defined-and-true macro. SafeUpload.Inspector.vcxproj:51 adds the
  SafeUploadStagingPrototype=true definition. Unset-property builds omit the
  feature protocol declarations and commands.
- D6: StageStream.c:154-238 uses a nonblocking interlocked writer reservation
  and publishes the reader high-water sequence only after slot commit.
  ReadBatch at :286-354 stops at an uncommitted slot without advancing its
  cursor. Contending trace writes increment LostEntries. Inspector main.c:692
  returns the current cursor in its summary so a later invocation can retry.
- D7: Existing message size/buffer validation, the pool scratch reply path,
  callback result paths, PASSIVE_LEVEL MmDoes call, and unregister/rundown
  ordering remain in place. Protocol.h:817-826 asserts the updated sizes and
  ProbeSkipReason offset.

Revised slice contract
- Feature-build-only and runtime default-OFF; all events are observational.
- The protected-create probe is the only extra I/O. It runs only after
  explicit enable on the disposable test VM and can wait like any lower create.
- Only known local fixed NTFS targets are probed. All unsupported cases are
  recorded as skips; paging/section stream context is intentionally unqueried.
- Directory skips are recorded at StageAdmit's existing early directory
  guard, before path-scope evaluation, so this reason can include directories
  outside protected scope. No name lookup was added to that guard.
- Event sequence numbers describe committed ring entries. The bounded writer
  drops on concurrent reservation contention rather than waiting; LostEntries
  counts those drops and ring overwrites.
