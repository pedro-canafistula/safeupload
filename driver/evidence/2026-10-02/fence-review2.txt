[BLOCKER] driver/SafeUpload.Minifilter/StageFence.c:377 - A prefix exactly equal to a volume name returns without scanning. SafeUploadPathUnderPrefix treats that prefix as covering every child, so policy activation succeeds with no coverage and status can say complete - scan the volume root for this prefix.
[BLOCKER] driver/SafeUpload.Minifilter/Policy.c:339-378; StageFence.c:523-556 - Policy and fence generations can diverge. SetPolicy can finish its pre-scan, then a concurrent control-11 refresh snapshots the old policy; SetPolicy swaps the new policy while that scan runs, and the old scan installs afterward. Until the post-swap scan completes, mapped writes in the new scope pass - serialize policy transition with all refresh installs or validate a generation before install and retry.
[BLOCKER] driver/SafeUpload.Minifilter/StageFence.c:495-498, 591-603, 613-620 - First nonempty publication stores FenceTable before its fast-path counts. A concurrent paging write (or create/name lookup or by-ID open) sees count zero and returns before taking the protecting lock - publish a synchronized state that cannot report empty before the table is visible, or remove the unsynchronized zero fast paths.
[BLOCKER] driver/SafeUpload.Minifilter/StageStream.c:1998-2001, 2033-2040 - A read-only create whose normalized-name query fails returns SUCCESS_NO_CALLBACK before consulting the fence. [BLOCKER] driver/SafeUpload.Minifilter/StageFence.c:285-307; Policy.c:339-378 - Directory enumeration is not a snapshot, and candidate paths are not protected until commit. An existing writable-mapped file can be hard-linked into a candidate directory after its enumeration cursor passes; the old-policy rename/link gate allows it, the candidate policy then activates, and paging writes arrive before the best-effort post-scan catches up - block/reconcile candidate-scope namespace changes across scan and commit.
[BLOCKER] driver/SafeUpload.Minifilter/Policy.c:890-902 - A valid full 260-WCHAR prefix (the string-table builder accepts an unterminated full slot) is silently omitted because CopyScope rejects lengths above 259 WCHAR. [BLOCKER] driver/SafeUpload.Minifilter/StageFence.c:242, 549-556; driver/SafeUpload.Inspector/main.c:716-724 - Reparse entries are skipped but do not fail the scan; a protected subtree reached through a junction can contain an unfenced mapped stream while LastStatus is success and complete is true - resolve/scan reparse targets or fail closed, and include skipped reparses in completeness.
