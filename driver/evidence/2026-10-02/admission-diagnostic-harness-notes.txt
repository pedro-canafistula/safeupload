## Runtime estimates and questions
- preattach-immediate: about 30-90 seconds; observes whether pre-attachment writeback reaches the trace, plus paired cached/uncached bytes without an earlier probe.
- preattach-protected-open: about 60-120 seconds; adds the in-scope protected read-only open before the old-view write and records its outcome.
- mmdoes-matrix: about 60-150 seconds; compares explicit-probe mmDoes, status, and SOP for closed writable, closed read-only, unmapped, and open-handle fixtures; SOP write comparisons use trace sequence windows.
- policy-transition: about 90-180 seconds; observes a mapping across baseline-policy push and scope expansion, with the old-view write while the expanded-policy agent is connected.
- R1/R2/R3 answer the cached-versus-uncached observer question for each applicable write ordering in this no-refusal run. Unknown #4 under an intentional paging-write refusal remains a separate test.
- All: estimate 4-8 minutes. Agent policy readiness can take up to 45 seconds per start, and every Inspector call has a 60-second default timeout.

## Output assumptions and limits
- Inspector entry keys used here are event, major, irpFlags, ownedStream, mmDoes, probeStatus, and sectionObjectPointer; explicit probe entries use event=explicit_probe. The final summary line uses summary=true and lostEntries / snapshotSequence.
- The explicit probe has no inline create-path dependency and does not require an agent or policy. Each Inspector task is SYSTEM because the port accepts only a SYSTEM primary token and one client at a time.
- Every fixture path component is checked for ReparsePoint before driver load; alternate-stream colons are rejected. A redirected Documents tree that contains a reparse component is outside this run's supported path setup.
- The native reader requires 4096 bytes to be a whole number of the volume's sectors and uses a VirtualAlloc buffer, offset zero, and a 4096-byte ReadFile.
- Trace events carry no file path. Matrix probe association follows sequential Inspector calls; write SOP equality is reported only when the trace sequence window yields one unambiguous SOP. Other cases are AMBIGUOUS or NoPagingEntry.
- The trace is bounded and may report lost entries. A timed-out probe does not cancel a lower open that may still be in flight; the harness stops the Inspector task, does not reconnect, runs restoration, prints InspectorTimeout=<command>, and returns failure. Follow the VM checkpoint procedure if restoration does not verify.
- The harness never enables Verifier and leaves raw trace JSON files in Documents as evidence.
