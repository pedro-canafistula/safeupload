SafeUpload Agent — candidato para validação em Windows 10/11 x64

Este pacote instala o serviço Windows e a interface de bandeja. O runtime .NET acompanha os executáveis.

Unidades SafeUpload (padrão): cada pasta protegida, pendrive e compartilhamento da política vira uma unidade (S:, T:, ...). O que o usuário grava é inspecionado antes de chegar ao destino real, e o driver gate recusa gravações diretas. Precisa do WinFsp e do driver gate: o instalador os instala quando o pacote os inclui; sem WinFsp instalado nem incluído, a instalação é recusada. O driver gate é assinado com o certificado de teste, então o Windows precisa estar em modo de teste. Não é preciso reiniciar.

Teste sem driver: observação de arquivos após a gravação, sem bloqueio preventivo no kernel. A instalação é recusada se houver um driver SafeUpload registrado. A inspeção TLS fica desligada nos dois modos.

A URL do servidor é opcional. Sem URL, o agente usa política local. A configuração de uma URL não comprova compatibilidade com a API web; alinhe o contrato com o responsável pelo backend.

Esta primeira versão aceita instalação inicial e desinstalação; atualizações de instalações existentes exigem um procedimento de manutenção separado.

O ZIP de atualização acompanha o procedimento manual setup/Update-SafeUploadAgent.ps1. Ele exige administrador, instalação gerenciada e pacote de versão posterior; mantém driver, configuração do serviço e dados do endpoint. Guarda a versão anterior e tenta recuperá-la se a nova não fica pronta. Consulte o README do instalador antes de executar. Não há atualização automática, reparo de instalação danificada nem atualização de driver neste procedimento.

Ao remover, a política, o cache, a fila de auditoria e os arquivos monitorados são preservados. O driver gate é removido junto com o agente; o WinFsp continua instalado.

O pacote de desenvolvimento não possui assinatura digital da equipe. Não foi validado para implantação em produção.
